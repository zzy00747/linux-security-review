## 🚀 使用

打开 [`index.html`](index.html) 即为资料索引页。

每一讲的页面有两个 tab：
- **📖 知识清单** — 按 Hook → 一句话结论 → 为什么 → 是什么 → 怎么用 → 自测 组织；右侧是原始 PPT 对照栏
- **📝 章节测试** — 点击作答，提交后自动批改并展开逐题解析

## 📖 复习建议

1. **第一轮（通读）**：按讲次顺序看知识清单，先读结论再读展开
2. **第二轮（对照）**：标题旁 `[页N]` 链接可跳到右侧对应幻灯片，核对老师原话
3. **第三轮（自测）**：切到章节测试做题，错题回到对应知识点重读
4. **第四轮（模考）**：做期末仿真卷，限时 120 分钟，做完再看答案页
